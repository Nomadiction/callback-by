# Заметки по списку сайтов

Список в [data/sites.json](../data/sites.json). Каждая запись:

```json
{"url": "https://example.by", "category": "marketplace", "enabled": true}
```

Поля:

- **url** — полный URL главной страницы (с протоколом).
- **category** — свободный тег для группировки (telecom, bank, marketplace, …). Не влияет на логику, используется для фильтрации в UI.
- **enabled** — если `false`, сайт исключается из прогона по умолчанию (но остаётся в редакторе UI).

## Поведение списка

- Стартовый `sites.json` пустой. Наполняется через UI (таб «Обслуживание» → «🌱 Запустить рост списка») или CLI (`python -m tools.grow_list --target 300`).
- Верификация (`verify_all` или `python -m tools.verify_sites`) **удаляет** нерабочие сайты из `sites.json` и переносит их в `data/excluded_domains.json`. Цель — чистый список без мусора.
- Чтобы пересмотреть отбракованные домены, используйте таб «🚫 Список исключений» (UI) или флаг `--rerun-excluded` (CLI).

## Когда добавлять сайт вручную

В UI таб «Обслуживание» → блок «➕ Быстрое добавление сайта» — он сразу проверяет URL и добавляет только при наличии формы. Подходящий сайт обычно:

- Продаёт услуги или товары с возможностью консультации.
- Имеет видимую кнопку «Перезвонить» / «Обратный звонок» / «Заказать звонок».
- Не требует логина для отправки формы.
- Не банк/гос-услуги (там обычно строгая верификация и капча).

## Автодобавленные сайты

При росте списка новые домены добавляются с `category: "discovered"` и `enabled: true`. Категорию можно поменять в редакторе («📋 Сайты»).
